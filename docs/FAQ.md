# FAQ — Notes MCP

**Q: How do I add a note?**  
Use the `add_note` tool with `title`, `category`, and `content`.

**Q: How do I search notes?**  
Use the `search_notes` tool with a search query (and an optional limit).

**Q: Where are notes stored?**  
All notes are stored locally in `data/notes.json`. No external API or authentication is required.
