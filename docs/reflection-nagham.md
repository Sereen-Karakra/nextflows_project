# My Final Reflection

## Wins

During the six weeks, I worked on building and finishing the MCP Notes Server with my teammate. I learned how MCP tools and resources work and helped make the project more complete by working with the Notes tools, validation, documentation, and final demo preparation. I also worked on the final public ship, tested the project from a fresh clone, tested the tools in MCP Inspector, and helped prepare the demo script and slides. In the end, we had a public repository with a working `v1.0.0` release.

## Blockers

One of the hardest parts for me was understanding how all the different parts of the project fit together, especially the MCP tools, resources, branches, and final release process. The final shipping stage was also challenging because I had to make sure the project worked from a completely fresh clone and that the Inspector test worked correctly. Preparing the final documentation and evidence also needed a lot of checking to make sure everything matched the requirements.

## Resume Bullet

Built and shipped a public TypeScript MCP Notes Server using MCP and Zod, with five working tools for searching, listing, adding, updating, and deleting notes. Tested the server with MCP Inspector, verified it from a fresh clone, and released the project as `v1.0.0`.
