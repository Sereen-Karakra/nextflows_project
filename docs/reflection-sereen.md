# Final Reflection

## Wins

During these six weeks, I worked on building and shipping a TypeScript MCP Notes Server using the Model Context Protocol (MCP) and Zod. I contributed to implementing and testing the Notes tools for searching, listing, adding, updating, and deleting notes, while also working with local JSON data to keep the project functional offline. I also worked on input validation, error handling, documentation, testing, and preparing the project for the final demo and public release.

One of my main achievements was helping make sure the final project worked correctly from a fresh clone and could be demonstrated using MCP Inspector. I also gained practical experience with Git, GitHub, MCP tools and resources, TypeScript, Zod validation, and preparing a project for a public release.

## Blockers

One of the harder parts for me was making sure that the final version of the project was correctly organized and that all changes were properly included in the `main` branch. Testing the project from a fresh clone was also challenging because it required checking that the setup and documentation were clear enough for someone who was not using my development environment.

Another challenge was making sure the tools handled invalid inputs and errors correctly while still providing clear responses. Preparing the final documentation, evidence, and demo also required careful checking before the final submission.

## Resume Bullet

Built and shipped a public TypeScript MCP Notes Server using MCP and Zod, contributing to five working tools for searching, listing, adding, updating, and deleting local notes. Worked on input validation, error handling, offline JSON storage, documentation, and testing. Verified the project from a fresh clone using MCP Inspector and contributed to the `v1.0.0` release.
